Один объект. Обязательное поле — project_name. Остальные (tagline, description, stars, repo_path, clone_url) — по желанию. Футер карточки — просто линия, без подписи.
Список объектов: [ {...}, {...} ]. Как только JSON — валидный список, ниже само появится по одному полю для фото на каждый элемент, с подписью из project_name. Номер и «всего» в футере («円相 · подборка · 01/0N») проставляются автоматически.
Один объект целиком описывает один стартап и всю карусель. Обязательные поля: project_name, stat_num (цифра-хук в кольце), hook_headline (заголовок обложки), slides — список ровно из 5 объектов (кто это был / момент казался идеальным / цифра / твист / что было дальше), каждый с tag, headline, body (список абзацев). И rebuild — объект с idea, stack, monetization. Внутри текстовых полей можно использовать <br>, <b> и <span class="accent">…</span> для переносов строк и выделения цветом — как в примере ниже. Результат — 8 картинок: telegram-обложка + 7 слайдов карусели, ничего больше вводить не нужно.
