# 円相 (Enso) — генератор карточек

Готовый JSON → PNG-карточки, отрендеренные headless-браузером — то есть
пиксель-в-пиксель как в браузере, со всеми шрифтами, градиентами и
эффектами.

Два **типа карточек** (`card_type` / `--type`), устроены по-разному:

- **`github`** — подборки GitHub-проектов. Нужно фото/скриншот на
  каждый элемент — оно вырезается по кольцу. Два режима: одиночная
  карточка (JSON-объект + фото) или подборка (JSON-список + фото по
  числу элементов). Результат — 3 формата на элемент: сторис
  (1080×1920), пост (1080×1350), telegram (1080×1080).

- **`startup`** — разбор ОДНОГО провалившегося стартапа. Только один
  режим: один JSON-объект → сразу весь пакет из **8 картинок**:
  telegram-обложка (1080×1080, для отдельного поста) + карусель из
  **7 слайдов** (1080×1350 каждый, для TikTok/Reels/Stories) —
  обложка-хук / кто это был / момент казался идеальным / цифра /
  твист / что было дальше / а как бы это собрать сегодня. Здесь нет
  фото (вместо него в кольце цифра-хук) и нет режима «подборка» — один
  стартап = один готовый пакет.

Веб-интерфейс работает **только с JSON** — никаких обращений к GitHub
API.

## Установка

```bash
pip install -r requirements.txt
playwright install chromium
```

(`playwright install chromium` качает сам браузер — нужно один раз,
требует интернет.)

## Веб-интерфейс

```bash
python app.py
```

Откройте `http://127.0.0.1:5000`. Сверху — переключатель типа
карточки: «⚙ GitHub-проект» / «☠ Провал стартапа».

- При **GitHub-проекте** ниже появляется ещё переключатель «Одиночный /
  Подборка», поле JSON и загрузка фото (одно или несколько).
- При **Провале стартапа** переключателя режима нет вообще — только
  одно большое поле JSON, без фото. Одна отправка формы — сразу весь
  пакет из 8 картинок.

После отправки — страница с превью всех карточек, кнопками «Скачать
PNG» под каждой и общей кнопкой «Скачать всё (.zip)».

## `card_type = github`

### Пример JSON — одиночная карточка

```json
{
  "project_name": "ai-job-search",
  "repo_path": "MadsLorentzen/ai-job-search",
  "clone_url": "https://github.com/MadsLorentzen/ai-job-search.git",
  "tagline": "Локальный ИИ-помощник для поиска работы — без данных на чужих серверах",
  "description": "Анализирует вакансии и подстраивает резюме под каждую из них — прямо на вашей машине, бесплатно и в открытом коде.",
  "stars": 22500
}
```

Обязательное поле — только `project_name`. Всё остальное необязательно:
- `stars` — число (`22500` → отформатируется в `22.5k`) или готовая строка (`"22.5k"`, `"1.2M"`).
- если `tagline` не задан, но задан `description` — тег-лайн соберётся из первых ~90 символов описания.
- если `clone_url` не задан, но задан `repo_path` — соберётся сам как `https://github.com/{repo_path}.git`.

### Пример JSON — подборка

Список объектов той же структуры:

```json
[
  {
    "project_name": "ai-job-search",
    "repo_path": "MadsLorentzen/ai-job-search",
    "tagline": "Локальный ИИ-помощник для поиска работы",
    "stars": 22500
  },
  {
    "project_name": "cal.com",
    "repo_path": "calcom/cal.com",
    "tagline": "Open-source альтернатива Calendly",
    "stars": 34000
  }
]
```

Фото загружаете в том же порядке — первое фото уйдёт первому элементу
списка и т.д. Количество фото должно совпадать с количеством элементов,
иначе форма вернёт понятную ошибку вместо генерации.

Номер (`index`) и общее число (`total`) в футере проставляются
автоматически по позиции в списке.

## `card_type = startup`

Один JSON описывает один стартап целиком — и обложку, и все 7 слайдов
карусели. Никакого списка, никакого фото.

### Пример JSON

```json
{
  "project_name": "Frank",
  "flag": "🇺🇸",
  "years": "2016 — 2023",
  "sector": "Financials",

  "stat_num": "$175M",
  "stat_label": "сожжено",
  "tagline": "Сервис для быстрого заполнения FAFSA — заявки на студенческую финпомощь в США",

  "hook_headline": "JPMorgan купил стартап за <span class=\"accent\">$175M</span>. Оказалось — липа",
  "hook_subhead": "Разбор реальной истории →",

  "slides": [
    {
      "tag": "Кто это был",
      "headline": "Frank<br><span class=\"accent\">США, 2016</span>",
      "body": [
        "Бесплатный сервис для заполнения FAFSA — формы на получение студенческой финансовой помощи в США.",
        "Обещали пройти пугающую бюрократию за <b>10 минут</b> вместо нескольких часов."
      ],
      "meta": "СЕКТОР <b>Financials</b> · ОСНОВАН <b>2016</b> · ЗАКРЫТ <b>2023</b>"
    },
    {
      "tag": "Момент казался идеальным",
      "headline": "Всё было<br>за них",
      "body": [
        "Растущий студенческий долг в США, спрос на «потребительский» UX даже в госуслугах.",
        "Основательница Charlie Javice стала звездой — Forbes 30 under 30."
      ]
    },
    {
      "tag": "Цифра, которая всё решила",
      "headline": "Frank заявлял:<br><span class=\"accent\">4,25 млн</span> пользователей",
      "body": ["Именно эта цифра привлекла JPMorgan, который заплатил <b>$175M</b>."]
    },
    {
      "tag": "Твист",
      "headline": "Реальных пользователей —<br><span class=\"accent\">~300 тысяч</span>",

    },
    {
      "tag": "Что было дальше",
      "headline": "Минюст США<br>предъявил обвинения",

    }
  ],

  "rebuild": {
    "idea": "Пошаговый помощник по целевому обучению и грантам — чеклист под вуз/регион, сроки подачи, шаблоны документов + база грантов и стипендий с фильтром по специальности и региону.",
    "stack": "Next.js + Supabase + Stripe/ЮKassa",
    "monetization": "Разовая оплата за проверку пакета документов или подписка для репетиторских центров, ведущих абитуриентов пачками."
  }

```

Быстро получить этот же пример: `python generate.py --type startup --json-example`.

### Поля верхнего уровня

| Поле | Обязательно | Что это |
|---|---|---|
| `project_name` | да | Название, попадает и в telegram-обложку |
| `stat_num` | да | Цифра-хук в кольце на обложке карусели (и на telegram-обложке), например `"$175M"`, `"14×"`, `"$1.7B"` |
| `hook_headline` | да | Заголовок слайда 1/7 (обложка карусели). Можно `<span class="accent">…</span>` для цветного акцента и `<br>` для переноса |
| `slides` | да | Список **ровно из 5** объектов — слайды 2–6, см. ниже |
| `rebuild` | да | Объект `{idea, stack, monetization}` — слайд 7/7, см. ниже |
| `stat_label` | нет | Подпись под цифрой в кольце, по умолчанию «сожжено» |
| `hook_subhead` | нет | Подзаголовок под обложкой, по умолчанию «Разбор реальной истории →» |
| `flag` | нет | Эмодзи-флаг страны (для telegram-обложки) |
| `years` | нет | «2016 — 2023» (для telegram-обложки и meta на слайде «Кто это был») |
| `sector` | нет | Сектор/индустрия (для telegram-обложки) |
| `tagline` | нет | Короткая строка под названием на telegram-обложке; если не задана — собирается из первых ~90 символов `description` |
| `description` | нет | Используется только для авто-сборки `tagline`, если он не задан |

### Каждый объект в `slides` (ровно 5 штук, по порядку: кто это был → момент казался идеальным → цифра → твист → что было дальше)

| Поле | Обязательно | Что это |
|---|---|---|
| `tag` | да | Маленькая надпись-рубрика над заголовком, например «Твист» |
| `headline` | да | Заголовок слайда. Можно `<br>`, `<b>`, `<span class="accent">…</span>` |
| `body` | да | Список строк-абзацев (обычно 1–2); можно `<b>…</b>` внутри |
| `meta` | нет | Плашка-строка снизу (обычно только на слайде «Кто это был»), например `"СЕКТОР <b>Financials</b> · ОСНОВАН <b>2016</b> · ЗАКРЫТ <b>2023</b>"` |

### `rebuild` (слайд 7/7)

| Поле | Обязательно | Что это |
|---|---|---|
| `idea` | да | Суть идеи-ребилда |
| `stack` | да | Технологический стек |
| `monetization` | да | Способ монетизации |
| `headline` | нет | Заголовок слайда, по умолчанию «Версия<br>для СНГ» |

### Разметка внутри текстовых полей

`hook_headline`, `headline` (в `slides`), `body`, `meta` рендерятся как
есть (без экранирования) — то есть внутри можно использовать:
- `<br>` — перенос строки в заголовке;
- `<b>…</b>` — жирное выделение внутри абзаца;
- `<span class="accent">…</span>` — покрасить часть текста в акцентный
  кирпичный цвет (используется в заголовках).

Так же вручную писали текст в первых версиях этих карточек — генератор
просто избавляет от необходимости трогать HTML/CSS напрямую.

## Использование из командной строки

**GitHub — одиночная карточка:**
```bash
python generate.py --json data.json --photo screenshot.png
```

**GitHub — подборка:**
```bash
python generate.py --batch list.json --photos p1.png p2.png p3.png
```
(фото — через пробел, по порядку элементов в `list.json`; количество
должно совпадать)

**GitHub — из самого GitHub** (данные подтягиваются автоматически, без JSON):
```bash
python generate.py owner/repo --photo screenshot.png
```

**Startup — пакет карточек одного стартапа:**
```bash
python generate.py --type startup --json startup.json
```

**Показать пример JSON:**
```bash
python generate.py --json-example                    # пример для type=github
python generate.py --type startup --json-example      # пример для type=startup
```

### Опции CLI

| Флаг       | Что делает                                                     |
|------------|------------------------------------------------------------------|
| `repo`     | (позиционный, опционально) `owner/repo` или ссылка на GitHub — только `--type github` |
| `--type`   | `github` (по умолчанию) или `startup`                           |
| `--json`   | путь к `.json` с ОДНИМ объектом — для `github` одиночная карточка, для `startup` единственный поддерживаемый режим |
| `--batch`  | путь к `.json` со СПИСКОМ объектов — подборка (только `--type github`) |
| `--photo`  | фото — для `--json` или `repo` (только `--type github`)         |
| `--photos` | фото по порядку — для `--batch` (через пробел, только `--type github`) |
| `--out`    | папка для результата, по умолчанию `./output`                   |

`--type startup` работает только с `--json` — без `repo`, `--batch`, `--photo(s)`.

### Результат

GitHub (`--type github`) — три PNG на карточку в папке `--out`:
```
output/
  ai-job-search-story.png     (1080×1920 — сторис)
  ai-job-search-post.png      (1080×1350 — пост в ленту)
  ai-job-search-telegram.png  (1080×1080 — telegram-пост)
```
Для подборки файлы дополнительно нумеруются префиксом (`01-...`, `02-...`).

Startup (`--type startup`) — восемь PNG в папке `--out`:
```
output/
  frank-telegram.png        (1080×1080 — обложка для отдельного telegram-поста)
  frank-slide01-cover.png   (1080×1350 — слайд 1/7, обложка-хук)
  frank-slide02.png         (1080×1350 — слайд 2/7, «кто это был»)
  frank-slide03.png         (1080×1350 — слайд 3/7, «момент казался идеальным»)
  frank-slide04.png         (1080×1350 — слайд 4/7, «цифра, которая всё решила»)
  frank-slide05.png         (1080×1350 — слайд 5/7, «твист»)
  frank-slide06.png         (1080×1350 — слайд 6/7, «что было дальше»)
  frank-slide07-rebuild.png (1080×1350 — слайд 7/7, «а как бы это собрать сегодня»)
```

Все PNG рендерятся с `device_scale_factor=2` — в 2 раза больше
номинального разрешения, для чёткости на любых экранах.

## Как это устроено

```
enso-card-generator/
  generate.py              — генератор (используется и CLI, и веб-интерфейсом)
  app.py                   — веб-интерфейс (Flask), только JSON, без GitHub
  ui_templates/
    index.html              — форма: тип карточки, для github — ещё Одиночный/Подборка
    result.html              — результат для type=github (сетка 3×N карточек + zip)
    result_startup.html      — результат для type=startup (telegram-обложка + галерея из 7 слайдов + zip)
  templates/
    story_1080x1920.html.j2             — GitHub-проект, сторис
    post_1080x1350.html.j2              — GitHub-проект, пост
    telegram_1080x1080.html.j2          — GitHub-проект, telegram
    startup_telegram_1080x1080.html.j2  — провал стартапа, отдельная telegram-обложка
    startup_carousel_cover.html.j2      — провал стартапа, слайд 1/7 (обложка-хук)
    startup_carousel_content.html.j2    — провал стартапа, слайды 2–6/7 (рендерится 5 раз с разным контентом)
    startup_carousel_rebuild.html.j2    — провал стартапа, слайд 7/7 (ребилд-идея)
  assets/
    enso-ring-transparent.png  — ваш реальный логотип-мазок с прозрачным фоном
  ui_uploads/               — временные загруженные фото (веб-интерфейс, только type=github)
  ui_output/                — результаты веб-интерфейса, по одной папке на job_id
  requirements.txt
```

Каждый `.html.j2`-шаблон — тот же HTML/CSS, что вы правили руками,
только с переменными вместо захардкоженного текста.

`generate.py` для `type=github`:
1. парсит JSON (объект — одиночная карточка, список — подборка; в
   GitHub-режиме вместо этого запрашивает `api.github.com`);
2. форматирует звёзды, собирает тег-лайн из описания, если не задан;
3. кодирует фото и кольцо в base64;
4. рендерит `story`/`post`/`telegram`-шаблоны с одним и тем же
   контекстом через `render_all()`.

`generate.py` для `type=startup` устроен иначе — контекст на каждом
слайде разный (текст, а не переиспользуемые поля):
1. `build_startup_package()` парсит и валидирует JSON целиком: что
   `slides` — ровно 5 объектов, `rebuild` содержит все три поля и т.д.
   — и раскладывает всё на 8 отдельных контекстов (telegram + 7 слайдов
   карусели), каждый ссылается на свой `.html.j2`;
2. `render_startup_package()` рендерит каждый контекст со своим
   шаблоном и своими размерами через Playwright, возвращает список
   путей к готовым PNG.

`app.py` — тонкая обёртка поверх тех же функций: парсит форму/файлы
(для `type=startup` — файлы не запрашиваются вообще, `mode` всегда
`startup`, режима «подборка» нет), для `github`-подборки ещё собирает
все PNG в `enso-cards.zip` (через `zipfile`) для одной кнопки «Скачать
всё» — то же самое делается и для пакета `startup` (8 файлов в один zip).

## Что можно донастроить

- **GitHub-режим CLI** остался (`python generate.py owner/repo --photo ...`)
  на случай, если когда-нибудь понадобится — просто в веб-интерфейсе он
  больше не показывается, только JSON.
- **Лимит GitHub API** (только для CLI-режима с `repo`) — без токена
  60 запросов в час на IP. Если понадобится больше — добавьте заголовок
  `Authorization: Bearer <токен>` в `fetch_repo()`.
- **Число content-слайдов в карусели стартапа** зафиксировано как 5
  (константа `N_CONTENT_SLIDES` в `generate.py`, итого 7 слайдов с
  обложкой и rebuild). Если понадобится другое число — поменяйте
  константу и добавьте/уберите валидацию в `build_startup_package()`.
- **Разное число фото/элементов в GitHub-подборке** — форма и CLI сразу
  укажут на несовпадение вместо того, чтобы упасть с неочевидной
  ошибкой.
