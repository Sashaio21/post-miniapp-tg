# Пакеты шаблонов

Шаблон = папка `packs/<id>/` (id: латиница, цифры, `-`, `_`). Новый шаблон добавляется без правки Python — достаточно скопировать папку.

```
packs/my-card/
  template.json      # описание (обязательно)
  template.html.j2   # Jinja2-шаблон (имя задаётся полем "file")
  assets/logo.png    # необязательно: в шаблоне {{ asset('logo.png') }}
```

`template.json`:

| поле | смысл |
|---|---|
| `name`, `description` | название и описание в галерее |
| `width`, `height` | размер карточки в px (PNG рендерится ×2) |
| `file` | главный HTML-файл пака (по умолчанию `template.html.j2`) |
| `example` | JSON-пример: подставляется в поле ввода и показывается на превью |
| `hint` | подсказка под полем JSON (простой текст) |
| `selector` | CSS-селектор элемента для скриншота (по умолчанию `.card`; нет такого — снимается вся страница) |
| `photo` | `"required"` / `"optional"` — показывать загрузку фото (нужен builder, который его использует) |
| `builder` | необязательно: Python-обработчик из `packs.py` (`github`, `startup_cover`, `startup_carousel`). Без него весь JSON передаётся в шаблон как есть; если JSON — список, на каждый элемент делается отдельная карточка |
| `order` | порядок в галерее |

Данные из JSON доступны в шаблоне как переменные (`{{ text }}`). Текст вставляется без экранирования — HTML-теги в значениях работают.
